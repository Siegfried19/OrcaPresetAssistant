# Orca Preset Assistant v0.6.3

这一版把 Codex 参数建议、Orca 权威写入和切片页原生 Undo 串成了一个可验证的闭环。

## 主要变化

- 最新修改使用单张卡片：应用、拒绝、失败和回滚更新同一张卡；新建议直接覆盖旧建议。
- 原生 Undo/Redo 与助手状态自动同步：支持完全回滚、部分回滚、第三值调整和恢复应用状态。
- revision 冲突会先刷新 Orca 权威状态，不再直接显示 `Native state revision is stale`。
- 只有原生写入回执和新 revision 数值都匹配时，才显示“已应用并验证”。
- 移除 Prepare 参数区由助手额外插入的提示/撤销横条，避免与 Orca 自身 Undo 和字段复原重复。
- Orca 原生 `writeCapabilities` 成为面板与 Codex 插件的唯一参数能力来源，并标记可见/隐藏参数。
- 新工作区可自动生成标准目录和 AI 操作指引；已有 `AGENTS.md` 永不覆盖。
- 修复 Windows 临时 Git 仓库路径别名识别与错误诊断丢失问题。

## 已验证

- TypeScript、ESLint、Prettier 与 Vitest：81 个通过，1 个按环境跳过。
- Codex 插件 MCP 集成测试：3 个通过。
- Orca 原生定向测试与 Windows Release 构建通过。
- 实机验证提案写入、Orca 原生 Undo 自动识别回滚，以及新提案覆盖旧卡片。

## 已知限制

- 当前为未签名的 Windows 早期预览版，Windows 可能显示未知发布者警告。
- machine 参数保持只读；枚举、脚本、路径、设备连接和运动安全参数不开放任意写入。
- `support_interface_loop_pattern` 是 Orca 原生可读写但无面板控件的隐藏参数。
- 新增或另存永久预设仍应先由 Orca 创建并注册，助手不会伪造其身份元数据。
